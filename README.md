# Vacancy Parser

Приложение на Java с использованием Spring Boot для работы с вакансиями. Проект находится в разработке.

## Технологии

- **Java 21** — язык программирования.
- **Spring Boot 3.5.6** — основа приложения.
- **Spring Web** — создание HTTP API.
- **Spring Data JPA** — работа с базой данных через ORM.
- **H2 Database** — встраиваемая база данных для разработки и тестирования.
- **Maven** — сборка проекта и управление зависимостями.

## Требования

Перед запуском убедитесь, что установлены:

- JDK 21;
- IntelliJ IDEA (рекомендуется);
- Git — при необходимости работы с системой контроля версий.

Maven отдельно устанавливать не нужно: в проекте используется Maven Wrapper.

## Запуск проекта

### 1. Клонирование репозитория

Если проект размещён в Git-репозитории:

```bash
git clone <https://github.com/kyoshisu/vacancy-parser>
cd vacancy-parser
```

Если проект уже находится на компьютере, перейдите в его корневую папку.

### 2. Проверка Java

В терминале выполните:

```bash
java -version
```

Убедитесь, что используется Java 21.

### 3. Проверка сборки

В Windows PowerShell выполните:

```powershell
.\mvnw.cmd clean package
```

Для проверки конфигурации Maven без полной сборки:

```powershell
.\mvnw.cmd validate
```

### 4. Запуск приложения

```powershell
.\mvnw.cmd spring-boot:run
```

## Разработка

Основной исходный код размещается в `src/main/java`, конфигурационные файлы — в `src/main/resources`, тесты — в `src/test/java`.

Для добавления новых зависимостей используется файл `pom.xml`.
